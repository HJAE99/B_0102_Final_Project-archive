- 전체 회의 결정 반영
  - 측정 칸은 0.5 m, 칸 상태는 미측정·미검출·음영·정상. 칸 값은 검출된 RSSI 의 중앙값, 음영 기준은 −72 dBm
  - 측정 맵은 DB 에 올려 두고 꺼내 씀. 회피 마스크는 관제가 DB 의 맵으로 냄 (시작부터 빈 마스크, 점검 전에 남은 칸)
  - 미측정 칸도 재측정 대상. 측정 경로 간격은 0.5 m. 두 로봇은 서로 기다리지 않음
  - RSSI 측정은 로봇 RPi 가 아니라 로봇 위에 얹은 로봇 PC 에서 함
  - 위 내용을 `docs/interfaces.md`(v0.2.11), 설계 문서, 요구사항, 시험 계획, Critical Path 에 반영해 main 에 올리고 팀 브랜치에 맞춰 넣음
